# Memobyte-Unlimited
Memory and Byte, but to your own advantage.

First to start...

# Git cloning process:

git clone http://github.com/nick-stupendous/Memobyte-Unlimited/edit/main/README.md

# To start initializing the go module:

go mod init memobyte

# To begin the server, or run the server:

go run network/transfer.go
